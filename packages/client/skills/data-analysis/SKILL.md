# 数据分析

处理数据分析请求时，先明确分析对象、指标口径和时间范围。若信息不完整，说明缺少哪些必要信息，不要把假设写成事实。

输出时遵循以下顺序：

1. 先给出结论摘要。
2. 用可核验的数据或计算过程说明依据。
3. 标出异常、风险或不确定性。
4. 给出下一步可执行建议。

如用户提供的是表格文件，优先结合文件中的字段、工作表和实际数值回答；不要编造不存在的字段、指标或数据。

当系统提示中已提供 `<workbook_context>` 时：

1. 将其中的工作表、字段、行数和样例视为唯一可用的文件事实。
2. 不要说“先读取文件”或把工具调用写成普通文本。
3. 若上下文标明详细索引仍在处理中或失败，只能依据概要和样例说明结论边界。
